# YaruDora Series Vol.1: Double Cast (PS1) — инструменты перевода

Порт английского фан-перевода PSP-версии (Cargodin & Esperknight) на оригинальную
PS1-версию и набор для русского перевода. В репозитории только код: образы игры,
извлечённый сценарий и текст перевода не выкладываются — всё собирается локально
из ваших образов.

Нужно: Python 3 + `openpyxl`, `xdelta3`.

## Английский

```
python3 port_english.py CD1.bin CD2.bin "Yarudora Portable - Double Cast.iso" patch.xdelta3 out
```
`patch.xdelta3` — из патчера английского перевода (папка `patch/`).

## Русский

```
python3 extract.py  CD1.bin CD2.bin script_ru.xlsx        # таблица реплик
# ...заполнить колонку «русский» (лист «Реплики»; имена — лист «Имена»)...
python3 make_patch.py CD1.bin CD2.bin script_ru.xlsx out  # образы + xdelta-патчи
```

Правила для текста в таблице:

* колонку «японский» не менять — по ней ищется строка в игре;
* «» печатаются как `""`, `…` → `...`, Ё → Е (в шрифте 64 буквы);
* латиница `C D Q S T W` (в любом регистре) и `# $ % & * / @ | ~ { }` — служебные коды движка,
  в тексте их использовать нельзя;
* переносы по словам делает сам движок; принудительный перенос — перевод строки в ячейке;
* если строка продолжает предыдущий кусок реплики (без 「」 в начале), начните перевод с пробела;
* в окне 3 строки: если реплика длиннее, начало уедет за экран — такие строки попадают в `warnings.txt`;
* пустые ячейки остаются японскими.

Интерфейс (карта памяти, настройки, Да/Нет) и имена персонажей уже переведены
(`tools/ui_ru.py`). По умолчанию включён режим «текст + голос».

Не переведена графика (кнопки титульного меню, меню настроек, экран управления).

Технические детали — в [docs/TECHNICAL.md](docs/TECHNICAL.md).
